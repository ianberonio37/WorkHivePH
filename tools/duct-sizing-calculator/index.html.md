# Duct Sizing Calculator

> The Duct Sizing Calculator uses the equal-friction method to size supply ductwork and find the critical-path pressure drop. Free online, with a worked example. Built for Philippine plants by WorkHive.

Source: https://workhiveph.com/tools/duct-sizing-calculator/

**The Duct Sizing Calculator uses the equal-friction method to size supply ductwork and find the critical-path pressure drop. Example: for a supply-air main carrying 2 m³/s (7200 m³/h) at 0.8 Pa/m friction over 20 m, Airflow = 7200 m³/h, Critical-path drop = 12.2 Pa, Friction rate = 0.8 Pa/m (per ASHRAE 2021 Ch.21 | SMACNA | ASHRAE 62.1).**
