How this page works

How to read this report: SPI above 1.0 means ahead of schedule. Figures come from the linked project’s live records. There is no cost performance index (CPI) here, and that is deliberate: the platform holds no cost ledger, so the only actual cost it can compute is logged hours × an assumed rate: labour alone. Dividing a whole-project budget by labour-only spend would flatter cost performance by whatever share of the budget is materials, equipment and contractors. The labour figure is shown on its own instead, labelled for what it is.

This report follows: PMBOK 7th ed., AACE 17R-97 (Cost Estimate Classification), AACE 80R-13 (Project Performance Measurement / EVM), IDCON 6-Phase shutdown management model, and ISO 21500:2021 (Guidance on project management). Critical path computed via Forward + Backward Pass (PMBOK §6.5.2.2). Earned Value formulas: PV = BAC × planned %, EV = BAC × actual %, SPI = EV / PV. CPI is deliberately omitted: it requires an actual cost, the platform holds no cost ledger, and labour hours × an assumed ₱200/hour covers only part of a project’s spend. Labour to date is reported as its own figure instead.
